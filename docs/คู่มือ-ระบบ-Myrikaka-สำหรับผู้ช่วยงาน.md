*(ฉบับ 6/9/2569 · เว็บระบบเวอร์ชัน v.0906-r7)*

เอกสารนี้อ่านจบประมาณ 20 นาที จะเข้าใจทั้ง **ธุรกิจพรีออเดอร์ของร้าน** ว่าเดินยังไง และ **เว็บระบบของเรา** ทำอะไรได้บ้าง รวมถึง **งานที่ค้างอยู่** และ **กฎเหล็กที่ห้ามละเมิด** ค่ะ

## ส่วนที่ 1 · ธุรกิจของร้านก่อน — พรีออเดอร์คืออะไร

ร้าน **myrikaka** ขายฟิกเกอร์/โมเดลอนิเมะญี่ปุ่นแบบ **สั่งจองล่วงหน้า (พรีออเดอร์)** ขายผ่าน 2 ช่องทาง: หน้าเว็บของร้านเอง + Shopee

ธุรกิจพรีออเดอร์ต่างจากขายของสำเร็จรูปตรงที่ **ลูกค้าจ่ายเงินก่อน แล้วของถึงทีหลังหลายเดือน** เพราะสินค้าบางตัวยังไม่วางขายที่ต้นทางด้วยซ้ำ ลำดับจริงคือ:

1. **ร้านประกาศสินค้า** จากเว็บต้นทาง (ญี่ปุ่น/จีน) พร้อมบอก "เดือนวางจำหน่าย" และ "วันปิดรับออเดอร์"
2. **ลูกค้าจ่ายมัดจำ** เพื่อการันตีที่ (ปกติจ่ายผ่าน QR/โอน แล้วแนบสลิปในเว็บ)
3. **พนักงานไป "กดของ"** ที่เว็บต้นทางจริง ๆ (สั่งจองกับร้านญี่ปุ่น/จีน) — นี่คืองาน "ใบสั่งซื้อ" ในระบบ
4. **รอของ** ตามเดือนวางจำหน่าย → ต้นทางส่งมาที่โกดังกลาง → **ขึ้นเรือ/รถมาไทย** (ช่วงนี้นานสุด เป็นเดือน)
5. **ของถึงไทย** → ร้านคิดค่าส่งในไทยแจ้งลูกค้า → ลูกค้าเก็บส่วนที่เหลือ + ยืนยันที่อยู่
6. **แพ็ก + ส่งพัสดุ** → กรอกเลขพัสดุในระบบ → ลูกค้าได้ของ → ปิดออเดอร์

เว็บของเราถูกออกแบบให้ครอบคลุม **ทุกขั้นตอนข้างบนนี้** — ลูกค้าใช้ฝั่งหนึ่ง พนักงานใช้อีกฝั่ง ข้อมูลอัปเดตพร้อมกันทุกเครื่องทันที

## ส่วนที่ 2 · ล็อตญี่ปุ่น vs ล็อตจีน — เส้นทางสินค้าต่างกัน (สำคัญมาก)

สินค้าของร้านมาจาก 2 เส้นทาง ระบบแยกให้ชัดด้วยคำว่า **"ล็อต"**:

| | 🇯🇵 ล็อตญี่ปุ่น (jp) | 🇨🇳 ล็อตจีน (cn) |
|---|---|---|
| ซื้อจาก | เว็บญี่ปุ่น เช่น AmiAmi, HobbyStock | โรงงาน/ร้านจีน เช่น Tmall, Bilibili |
| เงินต้นทาง | เยน (¥) | หยวน (元) |
| เดินทางมาไทยด้วย | **เรือ** (รอบขนส่งเรือ) | **รถของจีน** (รถบรรทุกข้ามประเทศ) |
| การเตรียมของ | ส่งตามปกติ | มักต้อง **"ตีลังไม้"** (ห่อไม้กันกระแทก — ลูกค้าเลือกได้ตอนสั่ง + มีค่าตีลังไม้เพิ่ม) |
| ค่าส่งมาไทย | คิดตามขนาดสินค้า (ระบบมีตารางแนะนำตามมิลลิเมตร) | คิดเป็นก้อนต่อชิ้น |

**ตอนคิดค่าส่งให้ลูกค้า** ต้องดูว่าสินค้านั้นอยู่ล็อตไหน เพราะเส้นทาง/ราคา/รอบเวลาต่างกัน ระบบเก็บ "ล็อต" ไว้ทุกสินค้าและทุกตัวเลือกอยู่แล้ว พนักงานแค่อ่านให้ถูกค่ะ

## ส่วนที่ 3 · ศัพท์ที่ใช้ในระบบ (ตารางกันงง)

| ศัพท์ในระบบ | แปลว่า |
|---|---|
| **เดือนวางจำหน่าย** | เดือนที่ต้นทางจะออกของจริง เช่น 12/2026 — ออเดอร์จะถูก**แยกไฟล์ตามเดือนวาง**อัตโนมัติ |
| **วันปิดรับ** | วันสุดท้ายที่รับออเดอร์เพิ่ม (ปกติปิดก่อนเดือนวาง ~7 วัน) |
| **มัดจำ** | เงินงวดแรกที่ลูกค้าจ่ายเพื่อการันตีที่ |
| **ค้างชำระรอบ 2** | ส่วนที่เหลือ (ค่าของ+ค่าส่ง) เก็บหลังของถึงไทย — ระบบแยกแท็บเดือนครบกำหนดให้ |
| **ราคาเต็ม (ราคาขีดฆ่า)** | ราคาปกติต้นทาง ไว้โชว์ขีดฆ่าให้ลูกค้าเห็นว่าถูกลง |
| **ราคาที่ลดแล้ว** | ราคาจริงที่ร้านจ่ายต้นทาง — **ใช้ตัวนี้คิดต้นทุนเสมอ** |
| **กดของ** | ไปสั่งจองกับเว็บต้นทางจริง ๆ (หลังลูกค้าจ่ายมัดจำแล้ว) |
| **รอบขนส่ง / รอบเรือ** | กลุ่มของที่ขึ้นเรือ/รถพร้อมกัน — ใช้กรองดูว่าของก้อนไหนกำลังมา |
| **รวมส่ง** | ลูกค้าหลายออเดอร์ขอรวมเป็นกล่องเดียวประหยัดค่าส่ง — ระบบมีคำขอรวมส่ง + รวม/แยกกลับได้ |
| **เครดิตลูกค้า** | เงินโอนเกิน/ทอน — เก็บไว้หักกับออเดอร์หน้าได้ ระบบจดให้ |
| **ใบปะหน้า** | สติ๊กเกอร์หน้ากล่อง ปริ้นจากระบบได้เมื่อของพร้อมส่ง |
| **หลักฐานการแพ็ก** | รูป/คลิปตอนแพ็กของ (แนบในระบบได้) — เป็นด่านบังคับก่อนส่งได้ |

## ส่วนที่ 4 · ชีวิตออเดอร์ 1 ใบ — สถานะทั้ง 7 (ตรงตามหน้าจอ)

ทุกออเดอร์ในหลังร้านมีแถบสถานะเดินได้ 7 ขั้น **ห้ามข้าม** ระบบจะกันบางขั้นเอง:

| # | สถานะ | ใครทำอะไร | ระบบกันอะไรไว้ |
|---|---|---|---|
| 1 | **คำสั่งซื้อใหม่** | ลูกค้ากดสั่ง+จ่ายมัดจำ+แนบสลิปเองในเว็บ | สลิปเข้ามาเป็น **"รอร้านตรวจ"** เสมอ — พนักงานต้องกดตรวจทีละใบ |
| 2 | **ตรวจสอบสลิปแล้ว** | พนักงานเทียบยอดในแอปธนาคารกับสลิป | ⚠️ ระบบ "ไม่ได้" เช็คกับธนาคารจริง — **ต้องดูยอดเองทุกใบ** (ระบบกันสลิปซ้ำเฉพาะเครื่องเดียวกันเท่านั้น) |
| 3 | **สั่งซื้อสินค้าแล้ว** | พนักงานกดของที่ต้นทางจริง | ระบบกันเดินสถานะล้ำ "เดือนวางจำหน่าย" — ของยังไม่วาง ห้ามไปต่อ |
| 4 | **กำลังเดินทางมาไทย** | ของออกจากโกดังต่างประเทศ (ระบุรอบขนส่งได้) | — |
| 5 | **สินค้าถึงไทยแล้ว** | ของเข้าโกดังไทย | หลังขั้นนี้ **ต้องคิดค่าส่งในไทยก่อนเสมอ** (ดูส่วนที่ 5) + ลูกค้าต้อง**ยืนยันที่อยู่** (ระบบนับอัตโนมัติ 7 วัน ถ้าไม่ยืนยันถือว่าใช้ที่อยู่เดิม) |
| 6 | **เตรียมจัดส่ง** | แพ็กของ + ถ่ายหลักฐานแพ็ก + ปริ้นใบปะหน้า | **ด่านบังคับ**: ต้องมีเลขพัสดุ **และ** หลักฐานการแพ็ก ถึงจะไปขั้น 7 ได้ |
| 7 | **จัดส่งในไทยแล้ว** | กรอกเลขพัสดุ (ระบบเดาขนส่ง+สร้างลิงก์ติดตามให้เอง) | ออเดอร์ปิดเองเมื่อทุกชิ้นส่งครบ |

> 💡 ทำไมต้องเป็นลำดับนี้: เพราะของพรีออเดอร์ "มาไม่พร้อมกัน" ลูกค้า 1 คนอาจมี 3 ตัว คนละเดือนวาง — ระบบจึงแยกสถานะ**รายชิ้น** (บางชิ้นถึงไทยแล้ว บางชิ้นยังอยู่ญี่ปุ่นได้ในออเดอร์เดียว) และแยกไฟล์ออเดอร์ตามเดือนวางให้เอง

### ค่าส่งในไทย — 4 สถานะที่พนักงานต้องเคลียร์ให้หมด
1. ⚠️ **ยังไม่ได้คิด** (ค่าเริ่มต้น 0 = ยังไม่ได้คิด ไม่ใช่ส่งฟรี!)
2. ⏳ **รอหารค่าส่งมาไทย** (ต้องรอเฉลี่ยค่าส่งของรอบนั้นก่อน)
3. 🎁 **ส่งฟรี** (พนักงานกดยืนยันเองว่าไม่คิด)
4. ✓ **คิดแล้ว** (มีตัวเลขจริง → ระบบปล่อยให้ลูกค้ายืนยันที่อยู่+แจ้งยอดสุดท้ายได้)

## ส่วนที่ 5 · เรื่องเงินทั้งระบบ

### อัตราแลกเงิน (เจ้าของแก้ได้)
- 1 เยน ≈ **0.255 บาท** · 1 หยวน ≈ **5.9 บาท** (โชว์มุมขวาบนเว็บ)

### สูตรตั้งราคา Shopee (คำนวณให้อัตโนมัติในเว็บ)
ช้อปปี้หักค่าธรรมเนียมรวมสูงสุด ~33.12% → **ราคาตั้งขาย = (ค่าของ + ค่าส่งในไทย + ค่าเอกสารใบจอง 10฿) × ~1.495**
เครื่องคิดแยกอยู่แท็บ 🟠 (มีปุ่มดูวิธีคิดทีละบรรทัด ใช้อธิบายลูกค้าได้)

### เครื่องมือเงินที่มีให้
- **แบ่งจ่าย**: ลูกค้าโอนก้อนเดียวมาหลายออเดอร์ — พนักงานกดแบ่งลงออเดอร์ได้
- **ค้างชำระ**: แท็บแยกตามเดือนครบกำหนด + แท็บ "รอชำระหลังสินค้าถึงไทย"
- **เครดิตลูกค้า**: โอนเกิน → เก็บเป็นเครดิต หักออเดอร์หน้าได้
- **รวมส่ง**: คำขอรวมส่งของลูกค้าเข้าคิวให้พนักงานตัดสินใจ

> ⚠️ **ยอดในระบบ = ตัวเลขช่วยจำ** การเงินจริงให้เทียบสลิปในแอปธนาคารเสมอ (สลิปซ้ำ/สลิปปลอม ระบบจับได้บางส่วน ไม่ทั้งหมด)

## ส่วนที่ 7 · สิทธิ์ 6 บทบาท (เจ้าของเป็นคนเปิดให้)

| บทบาท | ทำได้ | มองไม่เห็น |
|---|---|---|
| **เจ้าของร้าน** (Ning) | ทุกอย่าง รวมถึงตั้งค่าระบบ/สำรองข้อมูล/ลบ | — |
| **ผู้จัดการ** | ดูแลงานทั้งหมด เห็นยอดรวม | แก้ตั้งค่าระบบไม่ได้ |
| **แอดมินการเงิน** | ตรวจสลิป ยืนยันการชำระ | ยอดรวมทั้งร้าน |
| **แอดมินสั่งซื้อ** | ใบสั่งซื้อ + ข้อมูลสินค้า | ยอดเงิน |
| **แอดมินคลัง** | รอบขนส่ง เลขพัสดุ จัดส่ง | ยอดเงิน |
| **แอดมินแช็ต** | ข้อมูลลูกค้า + สถานะออเดอร์ | ยอดเงิน |

วิธีเพิ่มพนักงาน: ให้เขาสมัครบัญชีบนเว็บก่อน → เจ้าของไปที่ 🔒 ประวัติ & สิทธิ์ → ค้นหาอีเมล → เปิดสิทธิ์

## ส่วนที่ 8 · เพิ่มสินค้าใหม่ + ปุ่ม ⚡ (เวทมนตร์ของร้านเรา)

1. แท็บ 🎀 หลังร้าน → วาง**ลิงก์สินค้า**จากเว็บต้นทาง (วางได้หลายลิงก์ = หลายล็อต)
2. กด **⚡ ดึงข้อมูลอัตโนมัติ** → ระบบไปอ่านหน้าเว็บต้นทางเอง (ผ่านเซิร์ฟเวอร์ของเรา ไม่ใช่โหลดตรง) ได้ครบ: ชื่อ, ราคา 2 ตัว, รูป, ขนาด (มม.), ส่วนลด, วันปิดรับ, เดือนวาง, คำอธิบาย — มีสรุปผลทีละลิงก์ให้ดู (ชื่อ ✓ ราคา ✓ …)
3. **เช็คก่อนบันทึกเสมอ** — ระบบเดาให้ แต่ร้านต้องตรวจ (โดยเฉพาะวันปิดรับกับราคา)
4. กติกาภาษาที่ร้านตั้งไว้: **ชื่อสินค้า/ชื่อเรื่อง → อังกฤษ**, **คำอธิบาย → ไทย**, ชื่อแบรนด์คงทับศัพท์, ตัดชื่อเว็บต้นทางและโฆษณาออกจากชื่อเสมอ
5. บันทึกแล้วสินค้าขึ้นหน้าร้านทันทีทุกอุปกรณ์

## ส่วนที่ 10 · กฎเหล็ก 8 ข้อ (อ่านสองรอบ)

1. **สลิปทุกใบตรวจด้วยตาเอง** กับแอปธนาคาร — สถานะในระบบ "ผ่าน" ไม่ได้แปลว่าเงินเข้าจริง ระบบไม่ได้ต่อธนาคาร
2. **สถานะ 0 บาทค่าส่ง = ยังไม่ได้คิด** ไม่ใช่ส่งฟรี — ส่งฟรีต้องกดปุ่มเฉพาะ
3. **ห้ามข้ามสถานะ** — ระบบกันไว้ตามเดือนวางจำหน่าย ถ้ากัน แปลว่ามีเหตุผล
4. **อย่ากดปุ่ม 🧪 สร้างออเดอร์ทดสอบ** ในหน้าใช้งานจริงเด็ดขาด (มีแค่เจ้าของ/ผู้จัดการเห็น — มันสร้างข้อมูลปลอม 29 ใบเข้าระบบจริง)
5. **อย่าลบสินค้า** ถ้ามีออเดอร์ผูกอยู่ (ระบบจะไม่ให้ลบอยู่แล้ว) — ใช้ "ซ่อน" แทน
6. **สำรองข้อมูลทุก ≤ 7 วัน**: 🔒 ประวัติ → ปุ่ม ⬇️ (เก็บไฟล์ไว้ Google Drive ด้วย) — ระบบเตือนสีแดงเมื่อเกิน 7 วัน
7. **อย่าแก้ไฟล์โค้ดเอง** — ให้เจ้าของทำกับ Claude ทุกครั้ง (แก้ผิด = เว็บทั้งเว็บล่ม)
8. **ข้อมูลอัปเดตสดทุกเครื่อง** — คนอื่นแก้อยู่ เราจะเห็นทันที อย่าเปิดทิ้งไว้หลายวันโดยไม่รีเฟรช
