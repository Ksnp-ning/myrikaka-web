# 📢 คู่มือเปิดแจ้งเตือน LINE เมื่อมีออเดอร์ใหม่ — ร้าน Myrikaka

ระบบพร้อมแล้วทั้งหมดในโค้ด — เหลือแค่ตั้งค่า 2 อย่างบน Supabase + LINE ใช้เวลาประมาณ 15 นาที
ทำครั้งนี้ครั้งเดียวจบ ไม่ต้องทำซ้ำ และทำผิดขั้นไหนก็แค่ทำขั้นนั้นใหม่ ไม่มีอะไรพังค่ะ

---

## ขั้นที่ 1 · สร้าง Channel Access Token ของ LINE OA (≈ 7 นาที)

> ต้องมี LINE Official Account (OA) ของร้านอยู่แล้ว — @myrikaka ที่ใช้กับลูกค้าอยู่ ใช้ตัวนั้นได้เลย

1. เปิด https://manager.line.biz → ล็อกอินด้วยบัญชี LINE ของร้าน
2. เลือกบัญชีร้าน **Myrikaka** → ล้อกิ้นมุมขวาบน (รูปฟันเฟือง) → **Settings ทั่วไป**
3. เลือกเมนู **Messaging API** ที่แถบซ้าย → ถ้ายังไม่มี กด **เปิดใช้ Messaging API** → เลือก Provider (ใช้ชื่อ myrikaka ได้)
4. หน้าเดียวกัน เลื่อนลงมาที่ **Channel access token** → กด **Issue/Publish**
5. ก็อปตัวเลขยาว ๆ ที่ขึ้นมา (ขึ้นต้นประมาณ `eyJ...` ยาว ~200 ตัว) เก็บไว้ก่อน ← นี่คือ **TOKEN**

## ขั้นที่ 2 · เอา userId ของเจ้าของร้าน (≈ 3 นาที)

1. เปิด https://developers.line.biz/console/ → ล็อกอินด้วยบัญชีเดียวกัน
2. จะเห็น Channel ชื่อ Messaging API ที่เพิ่งเปิด → กดเข้าไป
3. แท็บ **Basic settings** → เลื่อนลงไปล่างสุดหา **Your user ID** → ก็อปค่าที่ขึ้นต้น `U` ตามด้วยตัวเลข 32 ตัว ← นี่คือ **USER ID**
4. ⚠️ อย่าใช้ Channel ID / Channel Secret — ต้องเป็น "Your user ID" ขึ้นต้น U เท่านั้น

> เคล็ดลับ: อยากให้เพื่อนร้านรับแจ้งเตือนด้วย → เพิ่มเพื่อนร้านเป็น **Admin** ใน LINE OA แล้วใช้ userId ของคนนั้นแทน (หรือให้ฉันต่อหลายคนในอนาคตได้ค่ะ)

## ขั้นที่ 3 · วางโค้ดฟังก์ชัน notify บน Supabase (≈ 3 นาที)

1. เปิดไฟล์ **`Downloads/myrikaka-app 3/supabase/functions/notify/index.ts`** ด้วย TextEdit
2. เลือกทั้งหมด (⌘A) ก็อป (⌘C)
3. เปิด **Supabase Dashboard** → เลือกโปรเจกต์ร้าน → เมนู **Edge Functions**
4. กด **Create a new function** → เลือก **Create via Dashboard** → ตั้งชื่อว่า `notify` (พิมพ์ตัวเล็กทั้งหมด)
5. กด **Create function** → ลบโค้ดตัวอย่างทั้งหมด → **วางโค้ด** → กด **Deploy**

## ขั้นที่ 4 · ใส่ TOKEN กับ USER ID เป็น Secrets (≈ 2 นาที)

1. อยู่หน้า Supabase เดิม → เมนู **Edge Functions** → เลือกฟังก์ชัน `notify` → แท็บ **Secrets** → **Add new secret**
2. เพิ่ม 2 รายการ:

| Name | Value |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | (TOKEN ยาว ๆ จากขั้นที่ 1) |
| `LINE_OWNER_USER_ID` | (USER ID ขึ้นต้น U จากขั้นที่ 2) |

3. กด Save ทั้งสองอัน

## ขั้นที่ 5 · เอาโค้ดล่าสุดขึ้นเว็บ + ทดสอบ (≈ 2 นาที)

1. ลากโฟลเดอร์ **`Downloads/myrikaka-deploy`** ไปวางที่ Netlify → Deploys ของเว็บร้าน (ตามเคย — ลาก "โฟลเดอร์" ไม่ใช่ไฟล์)
2. เปิดเว็บร้าน → รีเฟรชแบบบังคับ (**⌘+Shift+R**) → เช็คว่าหลังร้านขึ้น **v.0906-r7**
3. ทดสอบ: เข้าลูกค้า (อีกอุปกรณ์/หน้าต่างใหม่) → สั่งสินค้าจริง 1 ชิ้น → กดชำระ
4. ~3 วินาทีต่อมา LINE ของร้านควรได้ข้อความ "🔔 มีออเดอร์ใหม่..." พร้อมเลขออเดอร์ ลูกค้า ยอดเงิน และรายการสินค้า

## คำถามที่เจอบ่อย

**LINE ไม่มีข้อความมา — เช็คอะไรก่อน?**
① ขั้นที่ 5 ลาก deploy แล้วยัง · ② เพิ่มเพื่อน OA ของร้านด้วยบัญชี "เจ้าของร้าน" แล้วหรือยัง (LINE ส่ง Push หาคนที่เป็นเพื่อน OA เท่านั้น) · ③ Token ที่วางครบไหม (ลากดำคัดลอกมักตกหลุม — กดปุ่ม Copy แทน)

**แก้ข้อความแจ้งเตือนได้ไหม?**
ได้ — แก้ที่ฟังก์ชัน notify บรรทัด `const text = ...` แล้วกด Deploy ใหม่ หรือบอกฉันว่าอยากได้รูปแบบไหน (เช่น เพิ่มลิงก์เข้าหลังร้าน) เดี๋ยวทำให้ค่ะ

**อยากแจ้งเตือนอย่างอื่นด้วย (สลิปเข้า / สินค้าถึงไทย / ลูกค้าค้างชำระ)?**
บอกได้เลยค่ะ — โครงระบบพร้อมสำหรับเพิ่มเหตุการณ์อื่นอยู่แล้ว

**ยังไม่ตั้งค่าจะพังไหม?**
ไม่พังค่ะ — ยังไม่ใส่ Secrets ระบบจะข้ามการแจ้งเตือนเงียบ ๆ ทุกอย่างใช้งานปกติ
