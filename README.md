# 🎀 Myrikaka Web — ระบบร้านพรีออเดอร์ฟิกเกอร์

เว็บร้าน + ระบบหลังบ้านทั้งหมดอยู่ใน **ไฟล์เดียว**: [`index.html`](index.html)
เว็บจริง: https://myrikaka.netlify.app · เวอร์ชันปัจจุบัน: **v.0906-r7**

## โครงสร้าง

```
index.html                     ← โค้ดทั้งระบบ (HTML+CSS+JS ไฟล์เดียว)
supabase/functions/stock/index.ts   ← Edge Function ดึงข้อมูลสินค้าจากเว็บต้นทาง (ติดตั้งแล้ว)
supabase/functions/notify/index.ts  ← Edge Function แจ้งเตือน LINE (รอตั้ง Secrets)
supabase/sql/schema-v4.sql          ← SQL ที่ยังต้องรัน (สิทธิ์สลิปลูกค้าอัป Storage)
tests/ทดสอบ-ระบบดึงข้อมูล.mjs        ← ชุดทดสอบ 33 ข้อ (node ไฟล์นี้ — ต้องผ่านหมดก่อน merge)
docs/                               ← คู่มือระบบ + คู่มือติดตั้ง + คู่มือผู้ช่วยงาน
```

## กติกาการทำงาน (ห้ามข้าม)

1. **ก่อนแก้:** `git pull` ให้ล่าสุดเสมอ + คุยกันว่าใครแก้ส่วนไหนวันนี้
2. **แก้ใน branch ของตัวเอง:** `git switch -c ชื่องาน` (อย่าแก้บน main ตรง ๆ)
3. **ก่อนขอรวม (PR):** รันชุดทดสอบผ่าน 33/33 + ขยับเลขเวอร์ชันในโค้ด (ค้นหา `v.0906-r7` มีจุดเดียว + console.log ท้ายไฟล์) รูปแบบ `v.MMDD-rN`
4. **merge เข้า main = ขึ้นเว็บจริงอัตโนมัติ** ผ่าน Netlify (เช็ค chip เวอร์ชันบนหลังร้านเสมอหลัง deploy)
5. **ห้าม** commit service_role key / รหัสผ่านใด ๆ (anon key ในโค้ดเป็น public key by design)
6. **Supabase Dashboard:** รันเฉพาะ SQL แบบเพิ่ม policy/ตารางใหม่ + เก็บไฟล์ .sql ไว้ใน repo ทุกครั้ง — ห้ามแตะข้อมูลโดยไม่ปรึกษาเจ้าของ

## กับดักที่เคยเจอ (อ่านก่อนแก้ scraper/ฟอร์ม)

- ข้อความเว็บญี่ปุ่นมีช่องว่าง+ขึ้นบรรทัดยาว ~26 ตัวอักษรระหว่างป้ายกับตัวเลข → regex ตัวเลขใช้ `{0,22}–{0,30}`
- ราคา 2 ค่า: `priceJpy` (ลดแล้ว — ใช้คิดต้นทุน) / `listPriceJpy` (ราคาเต็ม — ขีดฆ่า) ห้ามหักส่วนลดซ้ำ
- สูตร Shopee: (ค่าของ + ค่าส่งไทย + เอกสาร 10฿) × ~1.495 (`CFG.spFeeVer:3`)
- ฟังก์ชันที่ถูกเรียกระหว่าง render ห้ามอ่าน element ที่ยังไม่ถูกวาด (เช็ค null ก่อน)
- `renderAll()` → `renderCur()` วาดเฉพาะหน้าที่เปิด — หน้าใหม่ต้องเพิ่มใน `renderCur` + `doSwitchTab`
- แท็บ 📤 Google Sheets เป็นโหมดจำลอง (ยังไม่มี network จริง)
- QR PromptPay ใช้ได้เมื่อ `CFG.shopPay.promptpay` ถูกกรอกจริง (by design — กัน QR เลขตัวอย่าง)
